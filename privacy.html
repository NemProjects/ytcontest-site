한국어

ytcontest(이하 "이 도구")는 운영자가 본인의 유튜브 계정을 관리하기 위해 쓰는 개인용 도구입니다.

  • 사용하는 데이터: Google 계정 인증(OAuth)으로 받은 권한으로 운영자 본인 계정에서 채널 구독, 영상 좋아요, 댓글 작성을 하고, 본인 계정의 구독·좋아요 상태를 확인합니다. 공개된 영상 정보와 공개 댓글을 YouTube Data API로 읽습니다.
  • 보관: 인증 토큰과 활동 기록은 운영자 개인 컴퓨터에만 저장되며 외부 서버로 보내지 않습니다.
  • 제3자 제공: 어떤 데이터도 판매하거나 제3자와 공유하지 않습니다.
  • 다른 사용자: 이 도구는 운영자 외 다른 사람에게 제공되지 않습니다. 다른 사람의 계정에 접근하지 않으며, 공개 댓글은 작성자 정보를 따로 모으지 않고 이벤트 참여 결과 확인에만 씁니다.
  • 권한 철회: Google 계정 권한 설정에서 언제든 접근 권한을 취소할 수 있습니다.

이 도구의 Google API 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. YouTube API 서비스를 사용하며, YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

English

ytcontest ("the tool") is a personal tool its operator uses to manage the operator's own YouTube account.

  • Data used: With permissions granted through Google OAuth, the tool subscribes to channels, likes videos, and posts comments on the operator's own account, and checks that account's subscription and rating status. It reads public video information and public comments through the YouTube Data API.
  • Storage: Authorization tokens and activity records are stored only on the operator's personal computer and are not sent to any external server.
  • Sharing: No data is sold or shared with third parties.
  • Other users: The tool is not offered to anyone other than the operator. It does not access other people's accounts, and public comments are used only to check event results, without collecting information about their authors.
  • Revoking access: Access can be revoked at any time in Google Account permissions.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; the YouTube Terms of Service and the Google Privacy Policy also apply.
